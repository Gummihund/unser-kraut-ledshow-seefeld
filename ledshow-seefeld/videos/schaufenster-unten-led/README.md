# Schaufenster unten LED

Hier werden die finalen Videos fuer das 192 x 128 px LED-Display unten im Geschaeft abgelegt.

Pflichtformat:

- MP4.
- 192 x 128 px.
- 30 fps.
- H.264, idealerweise Baseline.
- `yuv420p`.
- Ohne Audio.
- Keine Rotation.

Aktuell geprueft:

```text
DISPLAY-Schaufenster-226-192x128.mp4
```
